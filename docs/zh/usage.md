# 使用说明

## 添加数据源

点击工具栏的 **＋** 按钮，弹出三个选项：

| 操作 | 说明 |
| --- | --- |
| **打开文件** | 直接预览单个文件 |
| **打开文件夹** | 打开本地目录，进入文件树（可重复打开多个目录） |
| **添加连接** | 新建远程数据源（GitHub / GitLab / SFTP / WebDAV / S3 / HTTP） |

远程连接在弹窗里填写地址与凭证，保存后即出现在左侧「数据源」栏对应的分组下。

## 浏览

- **数据源栏**（左）：树形分组（本地 / GitHub / GitLab / SFTP / S3 …），点分组标题可展开/收起；本地分组下可同时挂多个已打开目录，按文件夹名显示，点条目切换。
- **文件树**（中）：顶部搜索框按文件名过滤；行内显示 文件类型图标 · 文件名 · 日期 · 大小；列宽不足时优先保住文件名，日期/大小自动省略号。
- **面包屑**（工具栏）：显示当前路径，逐级可点。
- **预览**（右）：选中文件即内联渲染。

## 多标签页

打开的文件会出现在预览上方的标签页栏，可同时开多个文件快速切换；标签页排满后可横向滚动（鼠标滚轮即可左右滑）。切换标签时，数据源栏和文件树的选中状态会自动跟随。

键盘快捷键：`←` / `→` 切换上一个/下一个文件。

## 全文检索

- 文件树顶部搜索框、或 `omniviewer search` 命令。
- 覆盖本地已索引目录 + 已缓存的远程文件。
- 中英文同等：中文走 jieba 分词 + 2-gram，英文走词元 + 标识符（camelCase/snake_case）拆分。
- 索引在后台增量维护，首次索引较大目录会稍慢。

## 水印

在「设置 → 水印」中配置：

- **明水印**：开关、文字、字体、字号、颜色（默认红色）、透明度、旋转角度、密度；对支持的格式（如 PDF）烘焙进文件。
- **暗水印**：抗截图点阵（屏幕水印）+ 用户标识；上传截图可解码出标识，用于泄露溯源。

## 下载与打包

- 右键文件/文件夹 → 下载；大文件自动分块、断点重试。
- 打包为 ZIP 时可选加密，密码在「设置 → 下载」里管理（可保存多个密码、选择、删除）。

## CLI

CLI 随应用打包，在「**设置 → 关于**」点「**安装 CLI 到 PATH**」后即可在终端使用（详见[安装说明](install.md)）：

```bash
omniviewer search  设计文档            # 全文检索
omniviewer search  设计文档 --remote   # 含已缓存远程文件
omniviewer index   /path/to/dir       # 重建索引
omniviewer cat     /path/file.md      # 输出文本内容
omniviewer ls      /path/to/dir       # 列目录
omniviewer status                     # 状态概览
```

## 接入 AI 智能体（MCP）

**本地智能体（stdio）**——以 Claude Desktop 为例，在 `claude_desktop_config.json` 添加：

```json
{
  "mcpServers": {
    "omniviewer": {
      "command": "omniviewer",
      "args": ["mcp"]
    }
  }
}
```

**远程智能体（Streamable HTTP）**——启动服务后，把端点配给远程智能体：

```bash
omniviewer mcp --http --host 0.0.0.0 --port 8765 --key <至少8位的密钥>
# 端点：http://<主机>:8765/mcp ，鉴权：Authorization: Bearer <密钥>
```

> 安全提示：`--host` 绑定非本机地址（非 127.0.0.1/localhost/::1）时必须提供 `--key`，否则拒绝启动。
