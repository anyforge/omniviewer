# 产品介绍

Omniviewer 是一款**跨源万能文件预览桌面应用**：把散落在本地磁盘、Git 平台、云存储、文件服务器上的文件，收拢到一个统一的三栏界面里查看、检索、引用。

## 定位

- **任何来源** —— 本地、GitHub、GitLab、HTTP、WebDAV、SFTP、S3，七大数据源并排浏览。
- **任何格式** —— 275+ 种格式内联预览，不下载、不开第三方软件。
- **一眼看清** —— 三栏布局（数据源 / 文件树 / 预览），所见即所得。

## 核心能力

1. **万能预览**：file-viewer 渲染内核，覆盖 Office 文档、PDF、代码、图片、音视频、压缩包、Markdown、EPUB 等。
2. **全文检索**：FTS5 + jieba 分词，中英文同等对待；本地与已缓存的远程文件统一命中，BM25 排序。
3. **水印溯源**：明水印（按格式烘焙）+ 暗水印（抗截图点阵），上传截图即可解码出用户标识。
4. **下载与打包**：文件/文件夹下载，加密 ZIP 打包（内置密码管理）。
5. **统一 CLI**：一个 `omniviewer` 二进制，十种子命令覆盖检索、索引、预览、缓存、水印、连接、MCP。
6. **MCP 服务**：把数据源与检索能力暴露给任意 AI 智能体（Streamable HTTP + stdio）。

## 架构

```
┌─────────────┐     ┌──────────────────────┐     ┌──────────────┐
│  前端        │────▶│  omniviewer-core     │◀────│  omniviewer  │
│  Tauri 2    │ IPC │  （Rust 核心库）        │     │  CLI + MCP   │
│  Vite 8     │     │  fs / 检索 / 缓存 /     │     │  clap + rmcp │
│  file-viewer│     │  水印 / 抽取           │     └──────────────┘
└─────────────┘     └──────────────────────┘
```

- **前端**：Tauri 2 + Vite 8 + TypeScript（vanilla），file-viewer Web Component 渲染。
- **核心库**：`crates/core`，GUI 与 CLI 共享同一套 Rust 逻辑（rusqlite/FTS5、jieba-rs、pdf-extract 等）。
- **CLI/MCP**：`crates/cli`，与 GUI 共用 `omniviewer-core`，单一二进制 `omniviewer`。

## 与 AI 结合

Omniviewer 的价值不止「人看」，还在于「智能体看」：内置 MCP 服务器把「你打开过的所有源」变成 AI 的检索与读取后端。智能体可以：

- 用 `search` 跨源检索你的文件全文；
- 用 `read_file` 直接读取 Office/PDF 的文本内容；
- 用 `list_files` 浏览目录、`get_file_info` 取元信息。

这使得一个「万能查看器」升维成「查看 + 检索引用」的 AI 工作台。
