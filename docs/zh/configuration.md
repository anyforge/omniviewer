# 配置说明

## 设置面板

工具栏齿轮进入设置，分五个标签页：

| 标签 | 内容 |
| --- | --- |
| **常规** | 语言（中/英）、主题（暗/亮）、界面缩放 |
| **主题** | 界面配色调色板（暗/亮）+ 代码配色调色板（Dracula / GitHub Light） |
| **水印** | 明水印（开关、文字、字体、字号、颜色、透明度、角度、密度）+ 暗水印（标识、屏幕水印、解码） |
| **下载** | 并发数、分块大小、Zip 加密密码管理（多密码保存/选择/删除） |
| **关于** | 版本号、作者（AnyForge）、检查更新、安装 CLI 到 PATH |

设置即时生效并持久化。

## 配置目录

所有运行时数据保存在用户主目录 `~/.omniviewer/`：

| 路径 | 用途 |
| --- | --- |
| `config.json` | 应用设置与数据源凭证（Unix 权限 600） |
| `index.sqlite` | 全文检索索引（FTS5） |
| `labels.json` | 远程文件缓存 → 源标识映射 |
| `cache/` | 预览缓存（含上限与淘汰） |

## 主题配色

主题通过「设置 → 主题」的**调色板**配置（存于 `config.json`）：

- **界面配色**：暗色 / 亮色两套，每套可调 背景、面板、浮起、边框、文字、次要文字、弱文字、强调色 共 8 个颜色。
- **代码配色**：暗色（默认 Dracula）/ 亮色（默认 GitHub Light）两套，每套可调 背景、前景、注释、关键字、字符串、数字、函数、类型、变量 共 9 个 token 颜色。

改色即时生效并持久化（界面 CSS 变量 + 代码语法高亮）；强调色的柔和背景色自动派生。

## 数据源凭证

远程连接的凭证（GitHub Token、SSH 密钥、S3 密钥等）保存于 `config.json`，设置连接后**缓存复用，无需重复输入**；在「添加连接」里可随时更换。

> 说明：当前版本凭证以明文存储、Unix 权限收紧到 600（仅本机用户可读）。操作系统钥匙串（macOS Keychain 等）将在应用签名发布后接入。

## MCP 服务参数

```
omniviewer mcp                        # stdio（默认）
omniviewer mcp --http                 # Streamable HTTP
  --host 0.0.0.0                      # 绑定地址（默认 127.0.0.1）
  --port 8765                         # 端口
  --key <密钥>                        # 鉴权密钥（≥8 位；绑定非本机地址时强制）
```

## 版本与变更

版本采用语义化（SemVer），变更记录见根目录 `CHANGELOG.md`。开发阶段规划与设计文档位于 `design/`（本地参考，不上传 GitHub）。
